# DSA Cheat Sheet

### Array Utilities

String to Array 
```java
str.toCharArray();
```
Array to String
```java
String.valueOf(arr)  or new String(arr)
```

Character checks
```java
// Letter and Digit check
Character.isLetter(ch);      // A-Z, a-z, and letters from other languages
Character.isDigit(ch);       // 0-9
Character.isLetterOrDigit(ch);

//White Space
Character.isWhitespace(ch);

// Case Utils
Character.isUpperCase(ch);
Character.isLowerCase(ch);

Character.toLowerCase(ch);
Character.toUpperCase(ch);

```
